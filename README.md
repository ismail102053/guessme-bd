# 🎯 GuessMe BD — বন্ধুরা তোমাকে কতটা চেনে?

বাংলা ভাষার ভাইরাল কুইজ-চ্যালেঞ্জ ওয়েবসাইট (ভার্সন ১)। নিজের সম্পর্কে ৩–১৫টি প্রশ্ন বানাও, লিংক শেয়ার করো, বন্ধুরা **লগইন/রেজিস্ট্রেশন ছাড়াই** খেলবে, আর তুমি **গোপন লিংকে** সবার স্কোর ও উত্তরের সারসংক্ষেপ দেখবে।

> **সৎ অবস্থা-প্রতিবেদন:** কোনটা আসলে পরীক্ষা করা হয়েছে আর কোনটা হয়নি — তা এই README-র [পরীক্ষার অবস্থা](#-পরীক্ষার-অবস্থা-কী-যাচাই-হয়েছে-কী-হয়নি) অংশে স্পষ্ট করে লেখা আছে। ডিপ্লয়ের আগে সেটি অবশ্যই পড়ো।

## 🧱 প্রযুক্তি ও স্থাপত্য-সিদ্ধান্ত

**স্ট্যাক:** Node.js ≥ 22.13 · নিজস্ব ছোট HTTP সার্ভার (বিল্ট-ইন `http`) · SQLite (`node:sqlite`) অথবা Turso (libSQL, HTTP) · ভ্যানিলা HTML/CSS/JS ফ্রন্টএন্ড।

**সবচেয়ে বড় সিদ্ধান্ত: শূন্য npm-নির্ভরতা।** `package.json`-এ `dependencies` খালি।

- **কেন?** উন্নয়নের সময় npm রেজিস্ট্রিতে পৌঁছানো যায়নি, তাই Node-এর বিল্ট-ইন ফিচার (`node:sqlite`, `fetch`, `crypto`, `http`, `node:test`) দিয়েই সব বানানো হয়েছে। এর সুফল: দ্রুত ডিপ্লয়, ছোট আক্রমণ-পৃষ্ঠ (supply-chain ঝুঁকি নেই), `npm install` প্রায় কিছুই ডাউনলোড করে না।
- **দাম:** ফ্রেমওয়ার্কের সুবিধা (Express ইত্যাদি) নেই; রাউটিং/ভ্যালিডেশন নিজে লেখা। `node:sqlite` Node ২২-এ এখনো "experimental" — চালুর সময় একটি সতর্কবার্তা আসে, Node-এর ভবিষ্যৎ সংস্করণে API বদলাতে পারে।
- **ফ্রন্টএন্ডে ফ্রেমওয়ার্ক নেই:** সব DOM `textContent` দিয়ে তৈরি (`innerHTML` নিষিদ্ধ — টেস্টে যাচাই হয়), তাই XSS-এর সুযোগ কম, আর কঠোর CSP (`script-src 'self'`) চালানো যায়।

**ডাটাবেসের দুই ড্রাইভার (`DB_DRIVER`):**

| ড্রাইভার | কখন | নোট |
|---|---|---|
| `sqlite` | লোকাল ডেভেলপমেন্ট, ভলিউমসহ VPS/Fly.io/Railway | একটি ফাইল (`data/guessme.db`), WAL মোড |
| `turso` | **Render/Vercel-এর মতো ফ্রি হোস্টিং** যেখানে ডিস্ক স্থায়ী নয় | ক্লাউড libSQL; HTTP প্রোটোকলে, কোনো প্যাকেজ ছাড়াই |

**কেন Turso?** ফ্রি-টায়ার হোস্টগুলোতে সাধারণত ডিস্ক মুছে যায়। Turso-তে ডেটা হোস্টের বাইরে থাকে, তাই রিডিপ্লয়/রিস্টার্টে কিছু হারায় না।

## 🚀 ইনস্টলেশন ও লোকাল ডেভেলপমেন্ট

### প্রয়োজনীয়তা
- **Node.js ২২.১৩ বা নতুন** (`node -v` দিয়ে দেখো)। [nodejs.org](https://nodejs.org) থেকে নামাতে পারো।
- আর কিছু লাগে না — কোনো ডাটাবেস সার্ভার, কোনো বিল্ড-টুল নয়।

### ধাপ

```bash
# ১. প্রজেক্ট ফোল্ডারে যাও (ZIP আনজিপ করার পর)
cd guessme-bd

# ২. নির্ভরতা ইনস্টল (কার্যত কিছুই নামায় না, তবু চালানো ভালো)
npm install

# ৩. পরিবেশ ফাইল বানাও
cp .env.example .env
#    (Windows CMD: copy .env.example .env)

# ৪. (ঐচ্ছিক ডেভেলপমেন্টে, প্রোডাকশনে বাধ্যতামূলক) গোপন সিক্রেট তৈরি করে .env-এ APP_SECRET= এর পর বসাও
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# ৫. সার্ভার চালু (প্রথমবার চালুতেই ডাটাবেস স্কিমা নিজে তৈরি হয়)
npm start
#    ফাইল বদলালে স্বয়ংক্রিয় রিস্টার্টসহ: npm run dev
```

ব্রাউজারে খোলো: **http://localhost:3000**

> 💡 `APP_SECRET` না দিলে ডেভেলপমেন্টে প্রতিবার চালুর সময় একটি অস্থায়ী সিক্রেট ব্যবহার হয় — চলবে, কিন্তু রিস্টার্টের পর খোলা কুইজ-পেজের "টিকেট" অকেজো হয়ে যায় (পেজ রিফ্রেশ করলেই ঠিক)। প্রোডাকশনে `APP_SECRET` না থাকলে সার্ভার **চালুই হয় না**।

### ফোনে লোকাল টেস্ট
একই Wi-Fi-তে থাকলে ফোনের ব্রাউজারে `http://<তোমার-কম্পিউটারের-আইপি>:3000` খোলো। (Facebook শেয়ার প্রিভিউ লোকালে কাজ করবে না — সেজন্য পাবলিক ডোমেইন লাগে।)

## ⚙️ এনভায়রনমেন্ট ভেরিয়েবল

পূর্ণ তালিকা ও ব্যাখ্যা `.env.example`-এ। প্রধানগুলো:

| ভেরিয়েবল | ডিফল্ট | বিবরণ |
|---|---|---|
| `NODE_ENV` | `development` | `production` দিলে কঠোর নিয়ম (সিক্রেট বাধ্যতামূলক, HSTS চালু) |
| `PORT` / `HOST` | `3000` / `0.0.0.0` | Render/Railway নিজেই `PORT` দেয় |
| `PUBLIC_BASE_URL` | খালি | সাইটের পূর্ণ ঠিকানা (`https://…`, শেষে `/` নয়)। Facebook প্রিভিউয়ের জন্য **প্রোডাকশনে সেট করো** |
| `DB_DRIVER` | `sqlite` | `sqlite` অথবা `turso` |
| `SQLITE_PATH` | `./data/guessme.db` | SQLite ফাইলের পথ |
| `TURSO_DATABASE_URL` | — | `libsql://…turso.io` (turso হলে বাধ্যতামূলক) |
| `TURSO_AUTH_TOKEN` | — | **গোপন** (turso হলে বাধ্যতামূলক) |
| `AUTO_MIGRATE` | `true` | চালুর সময় স্কিমা তৈরি/আপডেট |
| `APP_SECRET` | — | **প্রোডাকশনে বাধ্যতামূলক, ≥ ৩২ অক্ষর।** আইপি-হ্যাশ ও টিকেট সইয়ে ব্যবহৃত |
| `TRUST_PROXY_HOPS` | `0` | রিভার্স প্রক্সির পেছনে (Render, Railway, Fly) থাকলে `1`। ভুল দিলে রেট-লিমিট ঠিকমতো কাজ করে না — নিচের নোট দেখো |
| `RATE_LIMIT_*`, `MAX_*`, `MIN_MS_PER_QUESTION` | `.env.example` দেখো | রেট লিমিট ও স্প্যাম-সুরক্ষার সীমা |

**⚠️ `TRUST_PROXY_HOPS` নিয়ে সতর্কতা:** এটি ঠিক না হলে সব ব্যবহারকারী একই "আইপি" দেখা দেবে (প্রক্সির আইপি) — তখন একজনের কারণে সবার রেট লিমিট ফুরিয়ে যেতে পারে। Render/Railway/Fly-তে `1` দাও। Cloudflare-এর মতো আরেকটি প্রক্সি সামনে থাকলে `2`। সরাসরি ইন্টারনেটে থাকলে `0`।

**সিক্রেট নিয়ম:** `.env` কখনো Git-এ দিও না (`.gitignore`-এ আছে)। `TURSO_AUTH_TOKEN` ও `APP_SECRET` শুধু সার্ভারের পরিবেশ ভেরিয়েবলে থাকে; ফ্রন্টএন্ড কোডে কোনো সিক্রেট নেই (টেস্টে যাচাই হয়)।

## 🗄️ ডাটাবেস সেটআপ ও স্কিমা

### মাইগ্রেশন
- `src/db/migrations/*.sql` ফাইলগুলো নামের ক্রমে চলে; প্রয়োগ হওয়া সংস্করণ `schema_migrations` টেবিলে থাকে, তাই একই মাইগ্রেশন দুইবার চলে না।
- প্রতিটি মাইগ্রেশন একটি ট্রানজাকশনে চলে (ব্যর্থ হলে রোলব্যাক)।
- **স্বয়ংক্রিয়:** `AUTO_MIGRATE=true` হলে সার্ভার চালুর সময় চলে।
- **ম্যানুয়াল:** `npm run migrate`
- নতুন পরিবর্তন লাগলে `002_কিছু.sql` নামে নতুন ফাইল যোগ করো — পুরনোটা কখনো বদলিও না।

### স্কিমা (`001_init.sql`)

```
quizzes     id(PK) · owner_token_hash · creator_name · title · is_closed · question_count
            · creator_ip_hash · created_at
questions   id(PK) · quiz_id→quizzes · position · text · options_json · correct_index
attempts    id(PK) · quiz_id→quizzes · player_name · score · total · ip_hash · created_at
answers     (attempt_id→attempts, question_id→questions)(PK) · chosen_index · is_correct
```
- সব বিদেশি-কী `ON DELETE CASCADE`; ইনডেক্স আছে (আইপি-হ্যাশ+কুইজ+সময়, কুইজ+সময়)।
- `owner_token_hash` = টোকেনের SHA-256। **আসল টোকেন কখনো সংরক্ষিত হয় না।**
- `*_ip_hash` = প্রতিদিন-বদলানো HMAC। **কাঁচা আইপি কখনো সংরক্ষিত হয় না।**

### Turso সেটআপ (ফ্রি ক্লাউড ডাটাবেস)
1. [turso.tech](https://turso.tech)-এ অ্যাকাউন্ট খোলো।
2. ড্যাশবোর্ড বা CLI দিয়ে একটি ডাটাবেস বানাও।
3. ডাটাবেসের URL (`libsql://…`) কপি করো।
4. ওই ডাটাবেসের জন্য একটি **auth token** তৈরি করো (CLI: `turso db tokens create <db-name>`)।
5. দুটি মান `.env` (লোকাল) বা হোস্টের এনভায়রনমেন্টে বসাও এবং `DB_DRIVER=turso` দাও।
6. সার্ভার চালু করলেই স্কিমা তৈরি হবে (বা `npm run migrate`)।

> ⚠️ Turso-র বর্তমান ফ্রি-সীমা ও CLI কমান্ড বদলাতে পারে — সবসময় তাদের অফিসিয়াল ডকুমেন্টেশন দেখে নিও।

### ব্যাকআপ
- **SQLite:** সার্ভার বন্ধ রেখে বা `sqlite3 data/guessme.db ".backup backup.db"` দিয়ে ফাইলটি কপি করো (WAL মোডে `-wal`/`-shm` ফাইলসহ কপি করতে হয়, তাই `.backup` কমান্ড নিরাপদ)।
- **Turso:** তাদের ব্যাকআপ/ডাম্প সুবিধা দেখো।

## 🔐 নিরাপত্তা ও গোপনীয়তার নকশা

**ওনার-লিংক (গোপন ড্যাশবোর্ড):**
- কুইজ তৈরি হলে সার্ভার ২৫৬-বিট র‍্যান্ডম টোকেন (`crypto.randomBytes(32)`) বানায় এবং **একবারই** ব্রাউজারকে দেয়। ডাটাবেসে শুধু **SHA-256 হ্যাশ** থাকে — ডাটাবেস ফাঁস হলেও টোকেন উদ্ধার করা যায় না।
- গোপন লিংক: `/manage/<কুইজ-আইডি>#<টোকেন>`। টোকেন **`#`-এর পরে**, তাই ব্রাউজার সেটি সার্ভারে পাঠায় না → সার্ভার লগ, রিভার্স-প্রক্সি লগ, `Referer` হেডার কোথাও যায় না (E2E টেস্টে যাচাই হয়েছে: কোনো অনুরোধের URL-এ টোকেন ছিল না)। ম্যানেজ পেজে `Referrer-Policy: no-referrer`, `noindex`, `Cache-Control: no-store`।
- API-তে টোকেন যায় `Authorization: Bearer` হেডারে (URL/কুয়েরি-স্ট্রিংয়ে নয় — কুয়েরিতে দিলে ৪০৩, টেস্টে যাচাই হয়েছে)।
- তুলনা `timingSafeEqual` দিয়ে; কুইজ নেই/টোকেন ভুল — দুই ক্ষেত্রেই একই ৪০৩ বার্তা (কুইজের অস্তিত্ব বোঝা যায় না)।
- ভুল টোকেন বারবার দিলে আইপি ১৫ মিনিটের জন্য ব্লক (সঠিক টোকেন দিলেও — অনুমান-আক্রমণ ঠেকাতে)।
- **এই ডিভাইসে সুবিধার জন্য** টোকেন ব্রাউজারের `localStorage`-এ ("আমার কুইজ") সংরক্ষিত হয়। শেয়ার্ড/পাবলিক কম্পিউটারে কুইজ বানালে ব্রাউজার-ডেটা মুছে দাও।
- **টোকেন হারালে পুনরুদ্ধারের উপায় নেই** (আমাদের কাছে আসল টোকেন নেই) — ভার্সন ১-এ ইচ্ছাকৃত। ব্যবহারকারীকে তৈরির পর পেজে স্পষ্ট সতর্ক করা হয়।

**স্প্যাম ও অপব্যবহার সুরক্ষা (স্তরে স্তরে):**
1. আইপি-ভিত্তিক স্লাইডিং-উইন্ডো রেট লিমিট (মেমোরিতে): তৈরি, খেলা, পড়া, ওনার-অনুরোধ, অথ-ব্যর্থতা আলাদা কোটা।
2. ডাটাবেস-ভিত্তিক সীমা (আইপি-হ্যাশ ধরে): দৈনিক কুইজ-তৈরি সীমা, একই কুইজে ঘণ্টায় সর্বোচ্চ খেলা, প্রতি কুইজে মোট সর্বোচ্চ খেলোয়াড় — সার্ভার রিস্টার্টেও টেকে।
3. হানিপট লুকানো ফিল্ড (বট ভরে ফেললে প্রত্যাখ্যান)।
4. সার্ভার-সাইন করা "টিকেট": কুইজ খোলার সময় ইস্যু; খেলা জমা দিতে বৈধ টিকেট লাগে, ন্যূনতম সময় (প্রশ্ন × ৭০০ms) না গেলে "খুব দ্রুত" বলে প্রত্যাখ্যান, ৬ ঘণ্টা পরে মেয়াদোত্তীর্ণ।
5. নাম/শিরোনাম/প্রশ্ন/অপশনে লিংক ও ডোমেইন-সদৃশ লেখা নিষিদ্ধ (স্প্যাম-লিংক ঠেকাতে)।
6. কোনো **CAPTCHA নেই** — ইচ্ছাকৃত (ব্যবহারকারী-অভিজ্ঞতার জন্য)। লক্ষ্যবস্তু আক্রমণ হলে Cloudflare Turnstile যোগ করার কথা ভাবো।

**ইনপুট ও ডাটাবেস নিরাপত্তা:**
- সব SQL **প্যারামিটারাইজড** (`?`) — ইউজার ইনপুট কখনো SQL স্ট্রিংয়ে জোড়া হয় না।
- সার্ভারে কঠোর ভ্যালিডেশন: দৈর্ঘ্য, গণনা, টাইপ, ডুপ্লিকেট, নিয়ন্ত্রণ-অক্ষর/বাইডি-ওভাররাইড/অদৃশ্য অক্ষর ছাঁটা, Unicode NFC স্বাভাবিকীকরণ। বডির সীমা ৬৪ KB।
- **স্কোর সার্ভারেই গণনা** হয়; পাবলিক কুইজ API সঠিক-উত্তর পাঠায় না (খেলা জমার পরই রিভিউতে দেখায়)।
- আইডি `crypto`-র র‍্যান্ডম (১০ অক্ষর, ~৪৯ বিট) — অনুমান-অযোগ্য, কিন্তু আইডি জানলে কুইজটি পাবলিক (যেমন হওয়ার কথা)। রেজাল্ট-আইডি ১৪ অক্ষর।

**ওয়েব নিরাপত্তা:**
- কঠোর CSP: `default-src 'self'; script-src 'self'; style-src 'self'; frame-ancestors 'none'; object-src 'none'` — ইনলাইন স্ক্রিপ্ট/স্টাইল নেই (টেস্টে যাচাই), তাই XSS কঠিন। এছাড়া `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, প্রোডাকশনে HSTS।
- সব DOM তৈরি `textContent`/`createTextNode` দিয়ে; Facebook OG মেটাতে ইউজার-ডেটা HTML-এস্কেপড।
- CSRF: পরিবর্তনকারী অনুরোধে শুধু `application/json`, এবং `Origin` থাকলে আমাদের হোস্টের হতে হবে। কুকি/সেশন নেই, তাই CSRF-ঝুঁকি আরও কম।
- স্ট্যাটিক ফাইল: পাথ-ট্র্যাভার্সাল ঠেকানো, শুধু অনুমোদিত এক্সটেনশন, সোর্স/`.env`/ডাটাবেস ফাইল কখনো সার্ভ হয় না।
- ত্রুটিতে স্ট্যাক-ট্রেস/ডাটাবেসের ভেতরের তথ্য ক্লায়েন্টকে যায় না (শুধু `X-Request-Id`; লগে বিস্তারিত)।
- লগার রিকোয়েস্ট-বডি লেখে না এবং `token|secret|authorization|owner…` নামের ফিল্ড স্বয়ংক্রিয়ভাবে মাস্ক করে।

**গোপনীয়তা:**
- কাঁচা আইপি সংরক্ষিত হয় না — শুধু `HMAC-SHA256(APP_SECRET, দিন + আইপি)`-এর ১২৮ বিট। দৈনিক লবণ থাকায় আলাদা দিনের হ্যাশ মেলানো যায় না। (ক্ষণস্থায়ী মেমোরি-লিমিটারে কাঁচা আইপি থাকে, সার্ভার রিস্টার্টে মুছে যায়।)
- কুকি নেই, ট্র্যাকার/অ্যানালিটিক্স নেই, বাইরের ফন্ট/CDN নেই (সব `'self'`)।
- খেলোয়াড়ের নাম ও উত্তর শুধু কুইজ-মালিক দেখে। শেয়ার করা রেজাল্ট কার্ডে শুধু নাম ও স্কোর।
- মালিক যেকোনো সময় একটি উত্তর বা পুরো কুইজ স্থায়ীভাবে মুছতে পারে। `/privacy` পেজে সংক্ষিপ্ত গোপনীয়তা নীতি আছে — **আইনি পর্যালোচনা হয়নি**; ব্যবসায়িকভাবে চালালে নিজের প্রয়োজনমতো হালনাগাদ করো।

## 🔌 API সংক্ষিপ্ত রেফারেন্স

সব উত্তর JSON; ত্রুটি: `{"error":{"code":"…","message":"বাংলা বার্তা","fields":{…}}}` (৪২২-এ `fields` ফিল্ড-ভিত্তিক বার্তা দেয়, যেমন `questions.0.text`)।

## ⚠️ জানা সীমাবদ্ধতা ও ম্যানুয়াল সেটআপ

**তোমাকে নিজে করতে হবে:**
1. Turso অ্যাকাউন্ট/ডাটাবেস/টোকেন তৈরি (বা ভলিউমসহ SQLite হোস্টিং)।
2. হোস্টিংয়ে এনভায়রনমেন্ট ভেরিয়েবল বসানো (`APP_SECRET`, `PUBLIC_BASE_URL`, Turso মান, `TRUST_PROXY_HOPS`)।
3. ডিপ্লয়ের পর যাচাই-তালিকা (উপরে ধাপ ৪) চালানো।
4. কাস্টম ডোমেইন (ঐচ্ছিক) ও HTTPS (Render ইত্যাদি নিজেই দেয়)।

**ডিজাইনগত সীমাবদ্ধতা (ভার্সন ১):**
- **রেট-লিমিটার প্রতি সার্ভার-ইনস্ট্যান্সের মেমোরিতে।** একাধিক ইনস্ট্যান্স চালালে প্রতিটির আলাদা কাউন্টার থাকে। (ডাটাবেস-ভিত্তিক সীমাগুলো — দৈনিক তৈরি, কুইজ-প্রতি খেলা — সব ইনস্ট্যান্সের মধ্যে কাজ করে।) একটিমাত্র ইনস্ট্যান্সে (ফ্রি-টায়ারের স্বাভাবিক অবস্থা) কোনো সমস্যা নেই।
- **গোপন লিংক হারালে ফেরত পাওয়ার উপায় নেই।** (ইমেইল-রিকভারি ইচ্ছাকৃতভাবে নেই, কারণ অ্যাকাউন্ট/ইমেইল সংগ্রহ করতে চাইনি।)
- **খেলা শেষে সঠিক উত্তর দেখানো হয়।** তাই একজন বন্ধু উত্তর অন্যদের বলে দিতে পারে। কুইজ-খেলার মজার জন্য এই আপস রাখা হয়েছে; আইপি/কুইজ-প্রতি খেলার সীমা আছে, কিন্তু পুরোপুরি রোধ নয়।
- **একই ব্যক্তি আলাদা ডিভাইসে বা আইপি বদলে আবার খেলতে পারে।** লগইন-হীন সিস্টেমে এটি অনিবার্য।
- CAPTCHA, ইমেইল/পুশ-নোটিফিকেশন, অ্যাডমিন-মডারেশন প্যানেল, স্বয়ংক্রিয় ডেটা-মেয়াদ (পুরনো কুইজ মোছা) — ভার্সন ১-এ নেই।
- ডাটাবেস ড্রাইভারে `node:sqlite` ("experimental") — Node সংস্করণ বদলালে সতর্ক থাকো; `engines` ফিল্ডে `>=22.13` দেওয়া আছে।
- অ্যাডমিন হিসেবে অপব্যবহারকারী কুইজ মুছতে চাইলে সরাসরি ডাটাবেসে `DELETE FROM quizzes WHERE id = '…'` (এবং সম্পর্কিত টেবিল) চালাতে হবে।

## 🛠️ সমস্যা সমাধান

| লক্ষণ | সম্ভাব্য কারণ ও সমাধান |
|---|---|
| `SQLite is an experimental feature` সতর্কবার্তা | স্বাভাবিক — Node ২২-এর `node:sqlite` নিয়ে। উপেক্ষা করা যায়। |
| `ERR_UNKNOWN_BUILTIN_MODULE: node:sqlite` | Node-এর সংস্করণ পুরনো। `node -v` দেখো, ২২.১৩+ নাও। |
| সার্ভার চালু হয় না: "APP_SECRET বাধ্যতামূলক" | `NODE_ENV=production` হলে `APP_SECRET` (≥৩২ অক্ষর) দিতে হবে। |
| `/api/health` → `503` | ডাটাবেস সংযোগ ব্যর্থ। Turso হলে URL/টোকেন দেখো; SQLite হলে ফোল্ডারের লেখার অনুমতি দেখো। |
| সবার "অনেক বেশি অনুরোধ" ত্রুটি আসছে | `TRUST_PROXY_HOPS` ভুল (প্রক্সির পেছনে `1` হওয়া উচিত)। |
| লিংক-কপি কাজ করছে না | ব্রাউজার HTTPS ছাড়া ক্লিপবোর্ড-API আটকায়; ফলব্যাক চেষ্টা করে, না হলে লিংক চেপে ধরে কপি করতে বলে। প্রোডাকশনে HTTPS ব্যবহার করো। |
| Facebook-এ পুরনো/ভুল প্রিভিউ | Sharing Debugger-এ "Scrape Again"। `PUBLIC_BASE_URL` ঠিক আছে কি না দেখো। |
| ডেটা রিডিপ্লয়ে হারিয়ে যাচ্ছে | ফ্রি হোস্টে `sqlite` ব্যবহার করছ — `turso` ড্রাইভারে যাও বা স্থায়ী ভলিউম মাউন্ট করো। |
| "টিকেট" বা "পেজটির মেয়াদ শেষ" বার্তা | কুইজ-পেজ ৬ ঘণ্টার বেশি খোলা ছিল, বা সার্ভার `APP_SECRET` ছাড়া রিস্টার্ট হয়েছে — পেজ রিফ্রেশ করলেই ঠিক। |
